# Front-end Interview Notes

> Phase 3 · Index

Front-end study notes for experienced-level interviews: HTML, CSS, JavaScript and the browser platform, plus projects and round-specific interview preparation. Each topic folder has a `notes.md` and, where it helps, a small demo to run. Every note follows the same template: explanation, common mistakes, key takeaways, and interview questions in three tiers (Junior, Mid-level, Senior).

## How to use these notes

- **Learning a topic:** read the sections in order, run the demo, then try the interview questions before reading the answers.
- **Revising before an interview:** read each note's Key Takeaways and Common Mistakes, then answer its Senior questions out loud.
- **Interview fast track:** JavaScript 09–19 and 26, all of Browser platform, then the Interview section; use CSS 03, 06, 11, 13, 14 and 21 and HTML 06, 11 and 12 for the CSS and HTML rounds.
- **Running demos:** open HTML demos in a browser (or VS Code Live Server). JavaScript language demos run with Node, for example `node "03-javascript/19-event-loop/script.js"`.
