# But let's cover what TemplateBinding actually does, since it's a classic interview topic.

What it is

TemplateBinding is a lightweight binding mechanism used only inside a ControlTemplate. It binds a property of an element inside the template to a property of the control the template is applied to (the "templated 
parent").

Example — a custom template for a Slider or a custom NumericUpDown:

xml
<ControlTemplate TargetType="local:NumericUpDown">
    <Border BorderBrush="Gray" BorderThickness="1">
        <TextBlock Text="{TemplateBinding Value}" />
    </Border>
</ControlTemplate>

Here, whatever Value is on the NumericUpDown instance flows into the TextBlock.Text inside the template.

# What's the difference between UserControl and CustomControl? When would you build a CustomControl?

In WPF (and similarly in other XAML UI frameworks):
- UserControl is a reusable composition of existing controls. You build its UI directly in XAML and add code-behind if needed.
- CustomControl is a reusable control type designed to be styled, templated, and reused like built-in controls (Button, TextBox, etc.).

Use a UserControl when you want to package a fixed UI chunk—say, an address form, a search box, or a profile card. Its internal layout is usually part of its identity.

Build a CustomControl when consumers should be able to completely change the visual appearance without changing its behavior. A custom date picker, toggle, chart, or “status badge” intended for multiple themes is a 
good fit. You put its default look in Themes/Generic.xaml, expose dependency properties, and let templates/styles define its visuals.

|                             |  `UserControl`                              | `CustomControl` |
|---                          |---                                          |---|
| Best for                    | Reusable screen section                     | Reusable UI building block |
| Layout                      | Defined inside its XAML file                | Defined by a style/template |
| Can users replace its look? | Not naturally                               | Yes—by replacing its `ControlTemplate` |
| Typical example             | `ProfileCard`, `LoginForm`, `AddressEditor` | `Rating`, `ToggleSwitch`, `NumericUpDown` |
| Main files                  | `ProfileCard.xaml` + code-behind            | C# class + `Themes/Generic.xaml` |
| Theme support               | More limited / manual                       | Built for theming and skinning |


Here are small WPF examples of each.
>> UserControl: a reusable, fixed “profile card” view.

<!-- ProfileCard.xaml -->
<UserControl x:Class="MyApp.ProfileCard"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation">
    <Border Padding="12" CornerRadius="6" Background="LightGray">
        <StackPanel>
            <TextBlock Text="{Binding Name}" FontWeight="Bold" />
            <TextBlock Text="{Binding Email}" />
        </StackPanel>
    </Border>
</UserControl>

Use it directly:
<local:ProfileCard DataContext="{Binding SelectedUser}" />

Its layout is built into the control. Consumers can set properties/data, but normally do not replace its whole visual structure.

>> CustomControl: a reusable Rating control whose appearance can be changed through a template.
// Rating.cs
public class Rating : Control
{
    static Rating()
    {
        DefaultStyleKeyProperty.OverrideMetadata(
            typeof(Rating),
            new FrameworkPropertyMetadata(typeof(Rating)));
    }

    public int Value
    {
        get => (int)GetValue(ValueProperty);
        set => SetValue(ValueProperty, value);
    }

    public static readonly DependencyProperty ValueProperty =
        DependencyProperty.Register(
            nameof(Value), typeof(int), typeof(Rating),
            new PropertyMetadata(0));
}

Give it a default template in Themes/Generic.xaml:

<Style TargetType="{x:Type local:Rating}">
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="{x:Type local:Rating}">
                <StackPanel Orientation="Horizontal">
                    <TextBlock Text="★" FontSize="24" />
                    <TextBlock Text="{TemplateBinding Value}" FontSize="16" />
                </StackPanel>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>


Use it:
<local:Rating Value="{Binding ProductRating}" />
