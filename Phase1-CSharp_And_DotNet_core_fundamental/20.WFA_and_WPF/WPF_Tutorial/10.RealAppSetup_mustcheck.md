# This is the industry-standard approach for WPF apps

Use Visual Studio default WPF setup (`App.xaml` + `App.xaml.cs`).

When you create a WPF app, VS gives you:

```text
App.xaml
App.xaml.cs
MainWindow.xaml
MainWindow.xaml.cs
```

> **Note:** if these two — `App.xaml`, `App.xaml.cs` — are not there, then create them.

And startup looks like this:

```xml
<Application x:Class="MyApp.App"
             StartupUri="MainWindow.xaml">
</Application>
```

This is perfectly fine and recommended.

# How DI fits into the default setup (correct way)

- You keep the default setup
- You extend `App.xaml.cs`

## Step 1 — Remove StartupUri

```xml
<Application x:Class="MyApp.App">
</Application>
```

(So you control window creation)

## Step 2 — Use App.xaml.cs as Composition Root

```csharp
public partial class App : Application
{
    public static IServiceProvider Services { get; private set; }

    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);

        var services = new ServiceCollection();

        // Register services
        services.AddSingleton<IDialogService, DialogService>();
        services.AddSingleton<IFileDialogService, FileDialogService>();

        // Register ViewModels
        services.AddTransient<MainViewModel>();

        Services = services.BuildServiceProvider();

        // Create main window manually
        var mainWindow = new MainWindow
        {
            DataContext = Services.GetRequiredService<MainViewModel>()
        };

        mainWindow.Show();
    }
}
```

**Pros:**

- ✔ Visual Studio default
- ✔ Clean MVVM
- ✔ DI-friendly
- ✔ Production-ready

**Comparison (clear table)**

| Approach                           | Recommendation          |
| ---------------------------------- | ----------------------- |
| **Default App.xaml + App.xaml.cs** | ⭐⭐⭐⭐⭐ **Use this**      |
| Program.cs + Generic Host          | ⚠ Only if special needs |
| ServiceProvider inside ViewModel   | ❌ Never                 |
| ViewModel created in XAML          | ❌ Avoid                 |

# Best Practice Rule (memorize)

`App.xaml.cs` is the composition root for WPF:

- Register services
- Build DI container
- Create main window
- Inject ViewModels

# Common mistake ❌

Setting view model in XAML:

```xml
<Window.DataContext>
    <vm:MainViewModel />
</Window.DataContext>
```

**Why wrong?**

- No constructor injection
- No DI
- No testability

# Example

```text
App starts
  ↓
OnStartup
  ├─ setup DI
  ├─ setup logging
  ├─ setup handlers
  └─ show MainWindow
      ↓
      App running
      ↓
OnExit
  ├─ save settings
  ├─ flush logs
  └─ dispose services
```

| Method      | Called         |
| ----------- | -------------- |
| `OnStartup` | App launches   |
| `OnExit`    | App shuts down |

**What goes in OnExit**

✅ Cleanup logic only:

- Flush logs
- Save user settings
- Dispose services
- Close DB connections

- ❌ Do NOT show UI here
- ❌ Do NOT throw exceptions

## What goes in OnStartup (IMPORTANT)

✅ Things that should be initialized once:

- Dependency Injection container
- Logging (Serilog / NLog)
- Global exception handlers
- Main window creation
- Configuration loading

❌ Things that should NOT go here:

- Business logic
- UI logic
- Long-running operations

### 1. Recommended OnStartup template (Production)

```csharp
protected override void OnStartup(StartupEventArgs e)
{
    base.OnStartup(e);

    // 1️⃣ Global exception handling
    DispatcherUnhandledException += App_DispatcherUnhandledException;
    AppDomain.CurrentDomain.UnhandledException += CurrentDomain_UnhandledException;
    TaskScheduler.UnobservedTaskException += TaskScheduler_UnobservedTaskException;

    // 2️⃣ Configure services (DI)
    var services = new ServiceCollection();

    services.AddSingleton<IDialogService, DialogService>();
    services.AddSingleton<IFileDialogService, FileDialogService>();
    services.AddSingleton<IMessageBus, MessageBus>();

    services.AddTransient<MainViewModel>();

    Services = services.BuildServiceProvider();

    // 3️⃣ Create main window
    var mainWindow = new MainWindow
    {
        DataContext = Services.GetRequiredService<MainViewModel>()
    };

    MainWindow = mainWindow;
    mainWindow.Show();
}
```

### 2. Global exception handling (REAL apps must have this)

```csharp
private void App_DispatcherUnhandledException(
    object sender,
    DispatcherUnhandledExceptionEventArgs e)
{
    // log exception
    MessageBox.Show(
        e.Exception.Message,
        "Unexpected Error",
        MessageBoxButton.OK,
        MessageBoxImage.Error);

    e.Handled = true; // prevent crash if possible
}

private void CurrentDomain_UnhandledException(
    object sender, UnhandledExceptionEventArgs e)
{
    // log fatal crash
}

private void TaskScheduler_UnobservedTaskException(
    object? sender,
    UnobservedTaskExceptionEventArgs e)
{
    // log background task exception
    e.SetObserved();
}
```

### 3. Recommended OnExit template

```csharp
protected override void OnExit(ExitEventArgs e)
{
    try
    {
        // Save app state
        Properties.Settings.Default.Save();

        // Dispose services if needed
        (Services as IDisposable)?.Dispose();

        // Flush logs
        Serilog.Log.CloseAndFlush();
    }
    finally
    {
        base.OnExit(e);
    }
}
```

## Common shutdown scenarios (important)

| Scenario                 | OnExit called? |
| ------------------------ | -------------- |
| User clicks close        | ✅              |
| `Application.Shutdown()` | ✅              |
| Windows shutdown         | ✅              |
| Crash (unhandled)        | ❌              |

👉 That's why logging & exception handlers are critical.

# Example : extend to register multiple windows

## 1. Have WindowService (DialogService)

```csharp
public interface IWindowService
{
    void Show<TViewModel>();
    bool ShowDialog<TViewModel>();
}

public class WindowService : IWindowService
{
    private readonly IServiceProvider _services;
    private readonly IDictionary<Type, Type> _map;

    public WindowService(
        IServiceProvider services,
        IDictionary<Type, Type> map)
    {
        _services = services;
        _map = map;
    }

    public void Show<TViewModel>()
    {
        var window = CreateWindow(typeof(TViewModel));
        window.Show();
    }

    public bool ShowDialog<TViewModel>()
    {
        var window = CreateWindow(typeof(TViewModel));
        return window.ShowDialog() == true;
    }

    private Window CreateWindow(Type viewModelType)
    {
        if (!_map.TryGetValue(viewModelType, out var windowType))
            throw new InvalidOperationException(
                $"No window registered for {viewModelType.Name}");

        var viewModel = _services.GetRequiredService(viewModelType);
        var window = (Window)Activator.CreateInstance(windowType)!;

        window.DataContext = viewModel;
        window.Owner = Application.Current.MainWindow;

        return window;
    }
}
```

> **Note:** have dictionary containing all windows object, and DI Service provider.

- ✔ One place to manage windows
- ✔ Uses DI
- ✔ No window creation in VMs

## 2. Register windows and viewmodels (IMPORTANT)

**App.xaml.cs**

```csharp
protected override void OnStartup(StartupEventArgs e)
{
    base.OnStartup(e);

    var services = new ServiceCollection();

    // ViewModels
    services.AddTransient<MainViewModel>();
    services.AddTransient<SettingsViewModel>();
    services.AddTransient<AboutViewModel>();

    // Window mapping
    var windowMap = new Dictionary<Type, Type>
    {
        { typeof(MainViewModel), typeof(MainWindow) },
        { typeof(SettingsViewModel), typeof(SettingsWindow) },
        { typeof(AboutViewModel), typeof(AboutWindow) }
    };

    services.AddSingleton<IDictionary<Type, Type>>(windowMap);

    services.AddSingleton<IWindowService, WindowService>();

    Services = services.BuildServiceProvider();

    // Start main window
    var windowService = Services.GetRequiredService<IWindowService>();
    windowService.Show<MainViewModel>();
}
```

## 3. Use windows from MainViewModel (clean MVVM)

```csharp
public class MainViewModel
{
    private readonly IWindowService _windowService;

    public ICommand OpenSettingsCommand { get; }
    public ICommand OpenAboutCommand { get; }

    public MainViewModel(IWindowService windowService)
    {
        _windowService = windowService;

        OpenSettingsCommand = new RelayCommand(() =>
            _windowService.ShowDialog<SettingsViewModel>());

        OpenAboutCommand = new RelayCommand(() =>
            _windowService.Show<AboutViewModel>());
    }
}
```

## Note : Prevent multiple instances of same window (common need)

Inside `WindowService`:

Should have dictionary containing currently opened windows.

```csharp
private readonly Dictionary<Type, Window> _openWindows = new();

public void Show<TViewModel>()
{
    var type = typeof(TViewModel);
    // Find is this window is opened?
    if (_openWindows.TryGetValue(type, out var existing))
    {
        existing.Activate(); // if found then active it 
        return;
    }
    // if not then create it
    var window = CreateWindow(type);
    // setting event to remove window from dictionary while closing it 
    window.Closed += (_, _) => _openWindows.Remove(type);

    _openWindows[type] = window; // adding to opened window dictionary
    window.Show();
}
```

## 2. Configure appsettings in App.xaml.cs

This is the correct place.

```csharp
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;

public partial class App : Application
{
    public static IServiceProvider Services { get; private set; } = null!;
    public static IConfiguration Configuration { get; private set; } = null!;

    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);

        // Note : Recommended Host.CreateDefaultBuilder(args), use Generic Host
        // 1️⃣ Load configuration
        Configuration = new ConfigurationBuilder()
            .SetBasePath(AppContext.BaseDirectory)
            .AddJsonFile("appsettings.json", optional: false, reloadOnChange: true)
            .AddJsonFile($"appsettings.{Environment.GetEnvironmentVariable("DOTNET_ENVIRONMENT")}.json",
             optional: true)
            .AddEnvironmentVariables()
            .Build();

        // 2️⃣ Configure DI
        var services = new ServiceCollection();

        // Bind strongly typed settings
        services.Configure<ApplicationSettings>(
            Configuration.GetSection("Application"));

        services.Configure<MainWindowSettings>(
            Configuration.GetSection("Windows:MainWindow"));

        // Core services
        services.AddSingleton<IDialogService, DialogService>();
        services.AddSingleton<IWindowService, WindowService>();

        // ViewModels
        services.AddTransient<MainViewModel>();
        services.AddTransient<SettingsViewModel>();

        Services = services.BuildServiceProvider();

        // 3️⃣ Start Main Window
        var windowService = Services.GetRequiredService<IWindowService>();
        windowService.Show<MainViewModel>();
    }

    protected override void OnExit(ExitEventArgs e)
    {
        (Services as IDisposable)?.Dispose();
        base.OnExit(e);
    }
}
```

## 4. Use settings in Window creation (real-world use)

**WindowService (extend)**

```csharp
public class WindowService : IWindowService
{
    private readonly IServiceProvider _services;
    private readonly IDictionary<Type, Type> _map;
    private readonly IOptions<MainWindowSettings> _windowSettings;

    public WindowService(
        IServiceProvider services,
        IDictionary<Type, Type> map,
        IOptions<MainWindowSettings> windowSettings)
    {
        _services = services;
        _map = map;
        _windowSettings = windowSettings;
    }

    public void Show<TViewModel>()
    {
        var window = CreateWindow(typeof(TViewModel));

        if (window is MainWindow)
        {
            window.Width = _windowSettings.Value.Width;
            window.Height = _windowSettings.Value.Height;
        }

        window.Show();
    }

    private Window CreateWindow(Type vmType)
    {
        var vm = _services.GetRequiredService(vmType);
        var window = (Window)Activator.CreateInstance(_map[vmType])!;
        window.DataContext = vm;
        window.Owner = Application.Current.MainWindow;
        return window;
    }
}
```

# Recommended WPF setup (MODERN) using generic host

```csharp
public partial class App : Application
{
    private IHost _host = null!;

    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);

        _host = Host.CreateDefaultBuilder(e.Args)
            .ConfigureServices((context, services) =>
            {
                // ViewModels
                services.AddTransient<MainViewModel>();
                services.AddTransient<SettingsViewModel>();

                // Services
                services.AddSingleton<IWindowService, WindowService>();
                services.AddSingleton<IDialogService, DialogService>();

                // Window mapping
                services.AddSingleton<IDictionary<Type, Type>>(new Dictionary<Type, Type>
                {
                    { typeof(MainViewModel), typeof(MainWindow) },
                    { typeof(SettingsViewModel), typeof(SettingsWindow) }
                });
            })
            .Build();

        _host.Start();

        var windowService = _host.Services.GetRequiredService<IWindowService>();
        windowService.Show<MainViewModel>();
    }

    protected override async void OnExit(ExitEventArgs e)
    {
        await _host.StopAsync();
        _host.Dispose();
        base.OnExit(e);
    }
}
```
