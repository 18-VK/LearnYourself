## Master Your Project (This is 50% of the round)

You must be able to explain:

- Problem statement
- Architecture (how your app is structured)
- Tech stack (why .NET? why SQL?)
- Your role (very important)
- Challenges + how you solved them

💡 Example (How YOU should answer)

Instead of:

“I made a Web API using .NET”

Say:

“I built an ASP.NET Core Web API for user authentication using JWT. I designed controllers, used middleware for request handling, and implemented token-based security to protect endpoints.”

👉 This shows:

Clarity
Ownership
Real understanding

## Scenario-Based Questions (Most Important)

This is where most people fail.

Practice these:
🔴 Scenario 1:
API is slow in production
👉 Your answer:

Check logs
Identify bottleneck (DB / API / network)
Optimize query / caching
Scale if needed

🔴 Scenario 2:
You don’t know assigned technology
👉 Answer:

Break problem into parts
Learn quickly (docs, POC)
Ask team if needed
Deliver incrementally

🔴 Scenario 3:
Team member not contributing
👉 Answer:

Talk privately
Understand issue
Help if needed
Escalate if required

👉 They check:

Thinking approach
Maturity
Ownership
