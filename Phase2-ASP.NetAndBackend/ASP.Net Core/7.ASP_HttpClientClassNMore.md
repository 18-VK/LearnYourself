# HttpClient

The `HttpClient` class in .NET is the primary way to send HTTP requests and receive responses. It provides a modern, efficient, and asynchronous API for
interacting with web services and APIs.

## Key Concepts and Best Practices

- **Asynchronous Operations:**
  `HttpClient` methods are asynchronous by design, utilizing the `async`/`await` pattern, which prevents blocking the application thread and ensures scalability.
- **Instance Management:**
  A key best practice is to reuse a single `HttpClient` instance throughout the application's lifetime. Creating and disposing of an `HttpClient` for every request can lead to socket exhaustion and performance issues because underlying network connections are not released immediately.
- **IHttpClientFactory:**
  In modern ASP.NET Core applications, the recommended approach is to use the `IHttpClientFactory`. This factory manages the pooling and lifetime of the underlying `HttpMessageHandler` instances, addressing both socket exhaustion and issues with stale DNS entries that can occur with a single long-lived instance.
- **Configuration:**
  `HttpClient` instances can be configured with default request headers, a base address, timeouts, and other settings to streamline requests to specific APIs.
- **Handlers:**
  The actual network communication is handled by an `HttpMessageHandler` (typically `SocketsHttpHandler` in modern .NET). You can insert custom `DelegatingHandler` instances into the request pipeline for concerns like logging, authentication, or resilience policies (e.g., retries with the Polly library).

## Common Usage Patterns with IHttpClientFactory

In applications that use dependency injection, there are several ways to consume `HttpClient` via `IHttpClientFactory`:

- **Basic Usage:**
  Inject `IHttpClientFactory` into your service and call `CreateClient()` to get a new `HttpClient` instance.

  e.g.:

  ```csharp
  private readonly IHttpClientFactory _httpClientFactory;
  var httpClient = _httpClientFactory.CreateClient();
  ```

- **Named Clients:**
  Register and configure multiple clients with different settings (e.g., base addresses, headers) using `AddHttpClient(string name, ...)`. You retrieve them from the factory using their name.

- **Typed Clients:**
  This is often the preferred approach. You register a dedicated class that encapsulates the API logic:

  e.g. Typed Client:

  ```csharp
  // In Program.cs
  builder.Services.AddHttpClient<ISupplierHttpClient, SupplierHttpClient>(client =>
  {
      client.BaseAddress = new Uri("https://myapi.com");
  });
  ```

## Methods

The `HttpClient` class offers several asynchronous methods for different HTTP operations:

### GetAsync

Sends an HTTP GET request to a specified URI. Shorthand methods like `GetStringAsync`, `GetByteArrayAsync`, and `GetStreamAsync` are also available to retrieve
the response body directly as a string, byte array, or stream.

- `GetAsync(Uri, CancellationToken)`
  Send a GET request to the specified URI with a cancellation token as an asynchronous operation.

e.g.:

```csharp
var response = await client.GetAsync("api/products");
if (response.IsSuccessStatusCode)
{
    var data = await response.Content.ReadFromJsonAsync<List<Product>>();
}
```

**GetFromJsonAsync&lt;T&gt;() (BEST)**

👉 Shortcut for GET + deserialize

e.g.:

```csharp
var products = await client.GetFromJsonAsync<List<Product>>("api/products");
```

### PostAsync

Sends an HTTP POST request with a specified HTTP content to the URI.

- `PostAsync(String, HttpContent, CancellationToken)`
  Send a POST request with a cancellation token as an asynchronous operation.

- `PostAsync(Uri, HttpContent, CancellationToken)`
  Send a POST request with a cancellation token as an asynchronous operation.

- `PostAsync(String, HttpContent)`
  Send a POST request to the specified URI as an asynchronous operation.

- `PostAsync(Uri, HttpContent)`
  Send a POST request to the specified URI as an asynchronous operation.

e.g.:

```csharp
var content = new StringContent(json, Encoding.UTF8, "application/json");
await client.PostAsync("api/products", content);
```

### PostAsJsonAsync

👉 Most commonly used

```csharp
await client.PostAsJsonAsync("api/products", new
{
    Name = "Pen",
    Price = 10
});
```

### PutAsync

Sends an HTTP PUT request with specified HTTP content to the URI.

- `PutAsync(Uri, HttpContent)`
  Send a PUT request to the specified URI as an asynchronous operation.

- `PutAsync(Uri, HttpContent, CancellationToken)`
  Send a PUT request with a cancellation token as an asynchronous operation.

e.g.:

```csharp
var response = await client.PutAsync("api/products/1", content);
```

### PutAsJsonAsync()

```csharp
await client.PutAsJsonAsync("api/products/1", new
{
    Name = "Updated",
    Price = 20
});
```

Sends an HTTP DELETE request to the specified URI.

- `DeleteAsync(Uri)`
  Send a DELETE request to the specified URI as an asynchronous operation.

- `DeleteAsync(Uri, CancellationToken)`
  Send a DELETE request to the specified URI with a cancellation token as an asynchronous operation.

e.g.:

```csharp
await client.DeleteAsync("api/products/1");
```

### SendAsync

A general-purpose method for sending an `HttpRequestMessage` object, which allows for more control over the request configuration, including the specific HTTP
method and version.

- `SendAsync(HttpRequestMessage)`
  Send an HTTP request as an asynchronous operation.

- `SendAsync(HttpRequestMessage, CancellationToken)`
  Send an HTTP request as an asynchronous operation with cancellation token.

e.g.:

```csharp
var request = new HttpRequestMessage(HttpMethod.Get, "api/products");
var response = await client.SendAsync(request);
```

### CancelPendingRequests

Cancels all pending requests on the specific `HttpClient` instance.

## Key Properties

The `HttpClient` class includes properties to configure its behavior for all requests made by that instance:

### BaseAddress

Gets or sets the base URI for requests.

e.g.:

```csharp
client.BaseAddress = new Uri("https://localhost:5001/");
```

### DefaultRequestHeaders

Gets the default request headers that are sent with each request.

### Timeout

Gets or sets the default timeout value for all requests on this instance. If the timeout is reached, the request task is cancelled.

e.g.:

```csharp
client.Timeout = TimeSpan.FromSeconds(30);
```

👉 Prevents hanging requests

### MaxRequestContentBufferSize

Gets or sets the maximum number of bytes to buffer when an asynchronous operation is reading the response body.

### DefaultRequestVersion

Gets or sets the default HTTP version to use for requests (e.g., HTTP/1.1 or HTTP/2).

### Properties

Gets a writable dictionary of custom properties that can be used for custom handlers and special processing.
