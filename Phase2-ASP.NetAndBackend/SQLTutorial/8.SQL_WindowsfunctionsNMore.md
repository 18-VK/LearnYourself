# Window Functions

Window functions in SQL are powerful tools that perform calculations across a set of rows related to the current row, without collapsing the
result into a single row like traditional aggregate functions or `GROUP BY`. They are essential for tasks such as running totals, rankings, moving
averages, and comparing rows within a dataset.

They allow you to:

Perform calculations across a set of rows related to the current row
WITHOUT collapsing rows like `GROUP BY` does.

## Key Components of Window Functions

- **OVER() Clause:**
  Required to define the window (or we can say set of rows on which we will perform function). It specifies how rows are partitioned and ordered.
- **PARTITION BY:**
  Divides the result set into groups (partitions) based on a column. The function operates independently within each partition.
- **ORDER BY:**
  Controls the order of rows within each partition. It is required for ranking and value window functions.
- **Window Frame:**
  Defines the subset of rows within the partition used for the calculation (e.g., `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`).

**Syntax:**

```sql
FUNCTION_NAME() OVER (
    PARTITION BY column
    ORDER BY column
)
```

**Example:**

```sql
SELECT *,
       ROW_NUMBER() OVER (
           PARTITION BY Department
           ORDER BY Salary DESC
       ) AS DeptRank
FROM Employees;
```

**Is it mandatory to use window functions with OVER clause?**

Yes.
If you are using a window function, the `OVER()` clause is mandatory.
Without `OVER()`, it is no longer a window function.

# Common Types of Window Functions

## ROW_NUMBER()

Assigns a unique sequential number to each row within a partition. No ties.

**Example**

```sql
SELECT *,
       ROW_NUMBER() OVER (ORDER BY Salary DESC) AS RowNum
FROM Employees;
```

**Result**

| Name  | Salary | RowNum |
| ----- | ------ | ------ |
| Karan | 70000  | 1      |
| Aman  | 60000  | 2      |
| Rahul | 50000  | 3      |
| Neha  | 45000  | 4      |
| Priya | 40000  | 5      |

🎯 **Use Case**

- **Pagination:** Get records in small set
- **Top N records**
- **Deduplication:** Deduplication means removing duplicate rows from a table while keeping one valid record.

## RANK()

Assigns ranks with gaps when values are tied. For example, two tied 1st places result in ranks e.g. 1, 1, 3.

**Example**

```sql
SELECT *,
       RANK() OVER (ORDER BY Salary DESC) AS RankNum,
FROM Employees;
```

## DENSE_RANK()

Assigns ranks without gaps. Tied values get the same rank, and the next rank is consecutive e.g. 1, 1, 2.

**Example**

```sql
SELECT *,
       DENSE_RANK() OVER (ORDER BY Salary DESC) AS DenseRankNum
FROM Employees;
```

**Difference**

| Function   | Skips numbers? |
| ---------- | -------------- |
| RANK       | Yes            |
| DENSE_RANK | No             |

🎯 **Use Case**

- Leaderboards
- Top performers
- Competitive ranking

## PERCENT_RANK()

Returns the relative rank of a row as a percentage (0 to 1).

**Example:**

```sql
SELECT Name, Salary,
       PERCENT_RANK() OVER (ORDER BY Salary DESC) AS PercentRank
FROM Employees;
```

**Result**

| Name  | Salary | PercentRank |
| ----- | ------ | ----------- |
| Karan | 70000  | 0.00        |
| Aman  | 60000  | 0.20        |
| Rahul | 50000  | 0.40        |
| Neha  | 45000  | 0.60        |
| Priya | 40000  | 0.80        |
| Riya  | 40000  | 0.80        |

🧠 **Test Case Notes**

- Duplicate salaries share same percent rank.
- First row always 0.
- Last row always 1 (if more than 1 row).

🎯 **Use Case**

- Percentile ranking
- Performance grading
- Scholarship cut-offs

# Value Window Functions

## FIRST_VALUE()

Returns the first value in the ordered set.

**Example**

```sql
SELECT Name, Salary,
       FIRST_VALUE(Salary) OVER (ORDER BY Salary DESC) AS HighestSalary
FROM Employees;
```

**Result**

| HighestSalary |
| ------------- |
| 70000         |

🎯 **Use Case**

- Compare each employee with top salary
- Show highest price in report

## LAST_VALUE()

Returns the last value in the ordered set.

**Example**

```sql
SELECT Name, Salary,
       LAST_VALUE(Salary) OVER (
           ORDER BY Salary DESC
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS LowestSalary
FROM Employees;
```

**Result**

| LowestSalary |
| ------------ |
| 40000        |

> ⚠ **Interview Trap**
>
> Without frame clause: `LAST_VALUE` returns current row value.

## What Is a Window Frame?

When you use a window function like `LAST_VALUE()`, SQL needs to know:

👉 Over which rows should it calculate?

That range of rows is called the **window frame**.

**Syntax:**

```sql
OVER (
   ORDER BY column
   ROWS BETWEEN <start> AND <end>
)
```

**Meaning of Each Keyword**

| Keyword             | Meaning                           |
| ------------------- | --------------------------------- |
| UNBOUNDED PRECEDING | Start from first row of partition |
| UNBOUNDED FOLLOWING | Go until last row of partition    |
| CURRENT ROW         | Stop at current row               |
| n PRECEDING         | n rows before current row         |
| n FOLLOWING         | n rows after current row          |

**Your Query:**

```sql
SELECT Name, Salary,
       LAST_VALUE(Salary) OVER (
           ORDER BY Salary DESC
           ROWS BETWEEN UNBOUNDED PRECEDING 
           AND UNBOUNDED FOLLOWING
       ) AS LowestSalary
FROM Employees;
```

🧠 **What This Actually Does**

Sorts salaries in descending order.

Frame includes:

👉 From first row

👉 To last row

So the window includes entire result set.

`LAST_VALUE()` returns value of the last row in that ordered set.
Since ordering is DESC, the last row = lowest salary.
So every row will show the same value:

👉 The lowest salary in table.

## NTH_VALUE() (SQL Server 2022+)

Returns the nth value in the ordered set.

**Example**

```sql
SELECT Name, Salary,
       NTH_VALUE(Salary, 2) OVER (
           ORDER BY Salary DESC
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS SecondHighest
FROM Employees;
```

**Result**

| SecondHighest |
| ------------- |
| 60000         |

🎯 **Use Case**

- Second highest salary
- Third best performer

# Aggregate Window Functions

## SUM()

```sql
SELECT Name, Salary,
       SUM(Salary) OVER () AS TotalSalary
FROM Employees;
```

> `TotalSalary` = 315000 (repeated for each row)

## AVG()

```sql
SELECT Name, Salary,
       AVG(Salary) OVER () AS AvgSalary
FROM Employees;
```

> `AvgSalary` = 52500

## MIN / MAX

```sql
SELECT Name, Salary,
       MIN(Salary) OVER () AS MinSalary,
       MAX(Salary) OVER () AS MaxSalary
FROM Employees;
```

## COUNT()

```sql
SELECT Name,
       COUNT(*) OVER () AS TotalEmployees
FROM Employees;
```

> `TotalEmployees` = 6 (repeated per row)

# Partitioned Aggregate Example

Department average:

```sql
SELECT Name, Department, Salary,
       AVG(Salary) OVER (PARTITION BY Department) AS DeptAvg
FROM Employees;
```

# 🔥 Advanced Test Case — Running Total with Frame

```sql
SELECT Name, Salary,
       SUM(Salary) OVER (
           ORDER BY Salary DESC
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS RunningTotal
FROM Employees;
```

e.g. Running Total = all previous row salary + current row salary
